# صفحه اصلی دیکا آسیا

نسخه نهایی یکپارچه شامل هدر، ویدیوی اسکرولی و بدنه کامل صفحه اصلی است.

## اجرای محلی

پیش‌نیاز: Node.js 22

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## کنترل نسخه پروداکشن

```bash
npm run build
npm start
```

## استقرار روی Vercel

پروژه را در GitHub قرار دهید و همان مخزن را در Vercel Import کنید. تنظیم اضافه‌ای لازم نیست؛ Vercel دستورات Next.js را از `package.json` تشخیص می‌دهد.
